Conecte GitHub creando primero un espacio vacío en la web de GitHub. Después, en tu computadora, corrimos `git init` para que Git empezara a llevar la cuenta de los cambios en tu carpeta. Con `git add .` le dijimos qué archivos guardar (ignorando `.env` y `node_modules` gracias al `.gitignore`). Con `git commit` sacamos una foto de ese estado del proyecto. Con `git remote add origin` conectamos tu carpeta local con el espacio de GitHub, y con `git push` subimos esa foto a la nube. Lo único que trabó el proceso fue que GitHub ya no acepta contraseña normal por terminal, así que usaste un token en su lugar.

Con Firebase, VS Code no se conecta directamente con nada — solo es donde escribes el código. Lo que se conecta es tu proyecto con el proyecto de Firebase de la nube, y eso pasa por tres cosas: instalar el paquete con `npm install firebase` (el traductor que le enseña a tu código a hablar con Firebase), copiar las credenciales de la consola de Firebase a tu `.envgit push -u origin main` (la llave que identifica a qué proyecto pertenece tu código), y el archivo `config.js`, que junta esa llave con el paquete instalado para abrir la conexión real. Desde ahí, el resto de tu código ya puede guardar y leer datos sin repetir esa configuración.
